# 주말 H100 실험 사전 판정 기준

이 문서는 결과를 보기 전에 어떤 결과를 성공으로 판단할지 고정합니다.

## 주 가설

같은 검색 상태에서 측정한 문서 교체 점수는, 검색어 후보의 실제 최종 결과 순위를 행동 점수 자체의 반복 측정만큼 잘 재현하지 못한다.

## 표본

- `node8`: Qwen2.5-7B, 데이터셋 3개, BM25/E5, 조합당 고유 질문 30개
- 결과를 사용하지 않는 고정 해시 순서로 질문 선택
- 상태당 모델 생성 검색어 최대 6개
- 연속 실행 시드 4개
- 결과를 본 뒤 상태, 검색어, 교체 문서를 추가하거나 삭제하지 않음

## 주 문서 개입

상위 3개 문서 중 한 자리를 검색 순위 4~10위 문서로 교체합니다.
교체 문서는 원래 문서와 토큰 길이가 가장 비슷한 문서를 결과 확인 전에 선택합니다.

## 주 보상

`task = support_recall + 0.5 × answer_f1`

- `support_recall`: 정답을 뒷받침하는 근거 문서를 얼마나 찾았는지
- `answer_f1`: 생성 답변과 정답의 단어 겹침 점수
- 검색 횟수 패널티가 없는 점수를 주 결과로 사용
- answer F1, support recall, 검색비용 포함 composite를 민감도 분석으로 보고

## 행동–문서 감사 GO 조건

모두 통과해야 다음 단계로 진행합니다.

1. 계획 표본의 80% 이상 완료
2. 행동 점수의 반분 쌍별 일치도 0.65 이상
3. 시드를 절반으로 나눠 서로 다른 절반끼리 계산한 `행동 자기 일치도 − 문서/행동 일치도`의 질문 단위 95% 부트스트랩 구간 하한이 0보다 큼
4. 문서 점수의 정규화 top-1 regret 평균이 0.08 이상
5. 네 보상 관점 중 최소 두 개에서 신뢰도 차이의 95% 구간 하한이 0보다 큼
6. BM25로 정답 근거 제목을 그대로 검색한 공통 말뭉치 점검에서 recall@100이 0.90 이상
7. 교체 문서의 평균 상대 길이 차이가 0.35 이하
8. factual query와 직접 정책 샘플이 전체 후보의 65% 이상

**부트스트랩(bootstrap)**은 질문을 여러 번 다시 뽑아 결과의 불확실성을 계산하는 방법입니다.

## 정보이득 기준선의 범위

실제 검색 문서와 다른 질문에서 가져온 길이 맞춤 무작위 문서를 비교해, 정답 문자열의 교사강제 로그확률 차이를 계산합니다. 이 점수는 IG-Search의 핵심 아이디어를 오프라인 후보 설정에 맞춘 비교군이며 전체 온라인 GRPO 재현으로 부르지 않습니다. 후보의 90% 이상이 점수화되고 무작위 문맥의 평균 상대 길이 차이가 0.35 이하여야 유효 비교군으로 보고합니다.

## 그래디언트 주장 조건

- 모델 초기화 시드 3개 모두 완료
- 행동 반분 그래디언트 일치도와 행동–문서 그래디언트 일치도의 차이가 평균 0.05 이상
- 그 차이의 상태×초기화 시드 부트스트랩 95% 구간 하한이 0보다 큼
- 무작위 문서 점수의 행동 그래디언트 정렬도가 0.30 이하

## 학습 성능 주장 조건

독립 학습 시드가 방법당 최소 10개 있어야 합니다.

`outcome-plus-swap − outcome-only`의 선택 보상 차이에 대해:

- 평균이 +0.01 이상이고 95% 구간 하한이 0보다 크면 `학습 도움`
- 평균이 −0.01 이하이고 95% 구간 상한이 0보다 작으면 `학습 악화`
- 그 외에는 `명확한 학습 효과 없음`

인과적 충실도 결과와 학습 유용성 결과는 별도로 보고합니다.

## 결과와 무관하게 금지하는 주장

- 문서 점수는 항상 쓸모없다.
- 문서 점수는 모든 에이전트에서 항상 학습을 악화한다.
- 검색 에이전트 밖의 모든 도구 사용 환경에 일반화된다.
- 오프라인 미세 학습 결과만으로 완전한 온라인 강화학습 성능을 증명했다.
