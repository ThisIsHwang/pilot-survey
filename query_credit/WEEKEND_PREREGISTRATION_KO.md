이 문서는 결과를 보기 전에 표본, 런타임 모드와 성공 조건을 고정합니다.

- 모델: `Qwen/Qwen3.5-9B`
- 고정 리비전: `28a1d5547fecc4172665ca0ee26ea6c6dc8d3127`
- 추론 모드: `enable_thinking=false`
- 텍스트 전용 서빙: `--language-model-only`

- vLLM batch-invariant 모드: 사용하지 않음

Qwen3.5 GDN 계층에는 vLLM batch-invariant 커널을 사용하지 않으며, 동일 시드 재현성은 `max-num-seqs=1`과 시작 전 다중 GPU 동일 출력 검사로 확인합니다.

새 결과는 `work/query_credit_weekend_qwen35`에만 저장합니다. 공통 말뭉치와 BM25/E5 인덱스처럼 모델 출력에 의존하지 않는 자산만 무결성 검사 후 재사용합니다.

## 런타임 유효성 조건

다음 중 하나라도 실패하면 본실험 결과를 사용하지 않습니다.

1. 같은 시드의 동시 검사 요청이 글자 단위로 동일하지 않음
2. 응답의 `reasoning_content` 또는 `reasoning` 필드가 비어 있지 않음
3. 응답에 `<think>` 또는 `</think>`가 나타남
4. 실행별 누출 원장 `thinking_leaks.jsonl`에 한 건 이상 기록됨
5. 로컬 학습 토크나이저가 `enable_thinking=false` 가드를 설치하지 못함
6. 결과 경로가 Qwen3.5 전용 경로가 아님

## 주 가설

같은 검색 상태에서 측정한 문서 교체 점수는 검색어 후보의 실제 최종 결과 순위를, 행동 점수 자체의 반복 측정만큼 잘 재현하지 못한다.

## 표본

- `node8`: Qwen3.5-9B, 데이터셋 3개, BM25/E5, 조합당 고유 질문 30개
- 결과를 사용하지 않는 고정 해시 순서로 질문 선택

- 결과를 본 뒤 상태, 검색어, 교체 문서를 추가하거나 삭제하지 않음

## 주 문서 개입

상위 3개 문서 중 한 자리를 검색 순위 4~10위 문서로 교체합니다. 교체 문서는 정답과 결과를 보지 않고 원래 문서와 토큰 길이가 가장 비슷한 문서로 선택합니다.

## 주 보상

`task = support_recall + 0.5 × answer_f1`

- `support_recall`: 정답 근거 문서를 얼마나 찾았는지
- `answer_f1`: 생성 답변과 정답의 단어 겹침 점수
- answer F1, support recall, 검색비용 포함 composite를 민감도 분석으로 보고

## 행동–문서 감사 GO 조건

모두 통과해야 그래디언트와 학습 단계로 진행합니다.

1. 계획 표본의 80% 이상 완료
2. 행동 점수의 반분 쌍별 일치도 0.65 이상
3. `행동 자기 일치도 − 문서/행동 일치도`의 질문 단위 95% 부트스트랩 구간 하한이 0보다 큼
4. 문서 점수의 정규화 top-1 regret 평균이 0.08 이상
5. 네 보상 관점 중 최소 두 개에서 신뢰도 차이의 95% 구간 하한이 0보다 큼
6. 공통 말뭉치 점검 recall@100이 0.90 이상
7. 교체 문서의 평균 상대 길이 차이가 0.35 이하
8. 분석 후보의 100%가 같은 상태에서 Qwen3.5가 직접 생성한 검색 행동임
9. 추론 모드 누출이 0건
10. Qwen2.5 산출물이 Qwen3.5 결과 경로에 포함되지 않음

**부트스트랩(bootstrap)**은 질문을 여러 번 다시 뽑아 결과의 불확실성을 계산하는 방법입니다.

## 정보이득 비교군

실제 검색 문서와 다른 질문에서 가져온 길이 맞춤 무작위 문서를 비교해 정답 문자열의 교사강제 로그확률 차이를 계산합니다. 이는 IG-Search의 핵심 아이디어를 오프라인 후보 설정에 맞춘 비교군이며 전체 온라인 GRPO 재현으로 부르지 않습니다.

## 그래디언트 주장 조건

- 모델 초기화 시드 3개 모두 완료
- 행동 반분 그래디언트 일치도와 행동–문서 그래디언트 일치도의 차이가 평균 0.05 이상
- 차이의 상태×초기화 시드 부트스트랩 95% 구간 하한이 0보다 큼
- 무작위 문서 점수의 행동 그래디언트 정렬도가 0.30 이하

## 학습 성능 주장 조건

독립 학습 시드가 방법당 최소 10개 있어야 합니다.

`outcome-plus-swap − outcome-only`의 선택 보상 차이에 대해:

- 평균이 +0.01 이상이고 95% 구간 하한이 0보다 크면 `학습 도움`
- 평균이 −0.01 이하이고 95% 구간 상한이 0보다 작으면 `학습 악화`
- 그 외에는 `명확한 학습 효과 없음`

인과적 충실도와 학습 유용성은 별도로 보고합니다.
