# Qwen3.5 행동 후보와 입력 상태의 출처

## 왜 이 구분이 필요한가

기존 causal-query 상태 파일에는 이전 정책이 만든 검색 기록이 들어 있을 수 있습니다. 그 파일의 factual query를 그대로 사용하면 Qwen2.5가 만든 검색어를 Qwen3.5 행동으로 잘못 세는 문제가 생깁니다.

## 이번 5일 실험의 처리 방식

- 이전 상태 파일은 **고정된 평가 문맥**으로만 사용합니다.
- 개입 시점의 기존 factual query는 주 분석 후보에서 제외합니다.
- 통제형 source candidate도 주 분석에서 사용하지 않습니다.
- 비교하는 검색 행동은 모두 같은 고정 상태에서 비추론 모드 Qwen3.5-9B가 직접 생성합니다.
- 설정 게이트는 직접 Qwen3.5 행동 비율을 1.0으로 요구합니다.
- 원본 후속 실행, 문서 교체, 문서 제거, 정보이득, 그래디언트와 미세학습은 모두 Qwen3.5로 새로 계산합니다.
- 새 결과는 `work/query_credit_weekend_qwen35`에 저장하며 Qwen2.5 결과와 합치지 않습니다.

따라서 이번 결과가 답하는 질문은 다음입니다.

> 주어진 고정 검색 상태에서 Qwen3.5가 생성한 여러 검색 행동을 비교할 때, 각 행동이 가져온 문서의 크레딧이 행동의 결과 크레딧을 대신할 수 있는가?

## 왜 상태 문맥은 재사용할 수 있는가

이 실험의 핵심 비교는 같은 상태에 여러 Qwen3.5 행동을 넣는 짝지어진 실험입니다. 상태 문맥이 모든 후보에 동일하게 주어지므로, 문서 점수와 행동 점수의 차이를 비교하는 내부 타당성은 유지됩니다.

다만 이전 정책이 방문한 상태의 분포가 Qwen3.5가 실제로 자주 방문하는 상태의 분포와 다를 수 있습니다. 따라서 상태 재사용은 계산 절약을 위한 단순 캐시 재사용이 아니라, **고정 외부 상태에서의 조건부 실험**으로 명시합니다.

## 주장 경계

이 설계는 행동 후보의 모델 출처를 깨끗하게 만들지만, Qwen3.5가 처음부터 직접 방문한 상태만을 사용한 완전한 on-policy 실험은 아닙니다.

- **온폴리시(on-policy) 상태**: 현재 검사하는 모델이 직접 생성한 궤적에서 방문한 상태
- **고정 외부 상태**: 다른 정책이 만들었을 수도 있지만 모든 비교 조건에 동일하게 제공되는 상태

따라서 5일 실험만으로 “Qwen3.5가 실제 배포 중 방문하는 모든 상태에서도 같은 효과가 난다”고 주장하지 않습니다. 논문의 최종 보강 단계에서는 Qwen3.5가 질문 처음부터 생성한 궤적에서 작은 복제 실험을 추가하는 것이 좋습니다.

모델 전환 시 재실행 범위는 `query_credit/QWEN35_RERUN_MATRIX_KO.md`에 별도로 고정했습니다.
