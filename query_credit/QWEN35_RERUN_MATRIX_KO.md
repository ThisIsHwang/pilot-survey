# Qwen3.5-9B 전환 시 재실행 범위

## 원칙

모델이 Qwen2.5에서 Qwen3.5-9B로 바뀌면 모델 출력이나 모델 파라미터에 의존하는 결과는 이전 결과를 재사용하지 않습니다.

`캐시(cache)`는 이미 계산한 결과를 저장해 두었다가 다시 사용하는 파일입니다. 이번 실행은 Qwen2.5 캐시와 다른 `work/query_credit_weekend_qwen35` 경로를 사용하므로 두 모델의 결과가 섞이지 않습니다.

## 반드시 다시 계산하는 것

1. 같은 고정 상태에서 Qwen3.5가 직접 생성하는 검색어 후보
2. 각 검색어의 전체 후속 실행 결과
3. 각 문서를 고정 크기로 교체한 후속 실행 결과
4. 일부 상태의 문서 제거 민감도 결과
5. 행동 점수와 문서 점수의 일치도 및 신뢰도 분석
6. 정보이득 점수
7. 상태별 LoRA 그래디언트
8. 12개 학습 시드의 LoRA 미세학습과 평가
9. 모든 최종 주장 게이트와 보고서

## 그대로 재사용하는 것

다음은 모델 출력이 아니라 공통 실험 자산이므로 무결성 검사를 통과하면 다시 만들지 않습니다.

1. Wiki-18 원문 말뭉치
2. BM25와 E5 검색 인덱스
3. 데이터셋의 질문, 정답, 정답 근거 제목
4. 결과를 보기 전에 고정한 통계식과 성공 기준
5. 기존 상태 파일의 이전 검색 기록

마지막 항목은 **평가 문맥으로만** 재사용합니다. 이전 모델이 만든 검색어는 Qwen3.5 행동 후보나 행동 점수로 사용하지 않습니다.

## 이번 5일 실험의 주장 범위

모든 비교 검색어는 고정된 같은 상태에서 비추론 모드 Qwen3.5가 새로 생성합니다. 따라서 다음 질문에는 답할 수 있습니다.

> 주어진 검색 상태에서 Qwen3.5가 낼 수 있는 여러 검색 행동 가운데, 문서 수준 점수가 행동 수준 점수를 대신할 수 있는가?

다만 상태 자체가 이전 정책의 궤적에서 왔을 수 있으므로, Qwen3.5가 처음 질문부터 끝까지 직접 만든 모든 상태에 대한 완전한 `온폴리시(on-policy)` 실험은 아닙니다. 온폴리시는 현재 검사하는 모델이 직접 만든 궤적에서 상태와 행동을 모두 수집하는 방식을 뜻합니다.

## 실행 경로

Qwen3.5 전용 진입점만 사용합니다.

```bash
FORCE_CONTINUE=1 PROFILE=smoke \
  bash query_credit/run_qwen35_five_day.sh

PROFILE=auto bash query_credit/run_qwen35_five_day.sh \
  > logs/query_credit_qwen35_driver.log 2>&1
```

중단 후 같은 명령으로 재시작하면 Qwen3.5 전용 캐시만 이어서 사용합니다. Qwen2.5 결과는 삭제하지 않고 과거 파일럿 자료로 보존하지만, 새 분석에는 합치지 않습니다.
